# Selector Cine 365 para Android

## APK estable de GitHub

La APK pública está en la publicación v9.0.0. En la app aparece **Beta 13.13 Limpia**. Requiere Android 8 o posterior y usa el identificador es.cine365.app.limpia con versionCode 9027. [Descargar en GitHub](https://github.com/cristianbarallobre/selector-cine-365/releases/tag/v9.0.0)

Puede actualizar una instalación Limpia compatible si coincide la firma. Las ediciones es.cine365.app, es.cine365.app.limpia y es.cine365.app.preview tienen almacenamiento separado. Exporta un JSON desde Ajustes antes de desinstalar una edición o migrar a otra.

## Uso y sincronización

Utiliza la navegación inferior para acceder a la biblioteca, sorteo, estadísticas, listas y ajustes. En Ajustes están TMDB, la copia JSON y la cuenta Microsoft. Para sincronizar la edición estable, revisa los recuentos por lista y confirma la operación. El modo local está disponible sin conectar cuentas.

## Candidata para móvil y tablet

Android 9.2.4 se preparó como **Selector Cine 365 · Pruebas** con el identificador es.cine365.app.preview. Incluye Descubrir, Favoritos, sorteo inteligente, selección múltiple de plataformas y una ficha de disponibilidad por tipo de oferta. La APK estable de GitHub sigue siendo la edición Limpia.
