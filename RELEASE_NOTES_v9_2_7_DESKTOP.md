# Selector Cine 365 9.2.7

Versión estable para Windows de 64 bits y Mac Intel o Apple Silicon. Los paquetes Mac requieren macOS 12 o posterior y llevan firma ad hoc, sin notarización de Apple.

## Cambios de escritorio

- Favoritos conserva el orden manual y carga las fichas aunque la película solo esté en esa lista. Los títulos con el mismo ID de TMDB comparten corazón y valoración.
- Añadir a Favoritos marca como vista la película cuando ya está en otras listas. La edición de listas permite conservarla solo en Favoritos.
- El sorteo admite varias plataformas y la recepción automática de OneDrive mantiene la página activa. El selector de listas se alinea con el panel de sorteo.
- Las identificaciones de TMDB con otro año se pueden guardar tras confirmar el aviso. Mac protege la sesión Microsoft en el llavero y separa la caché de los datos personales.

## Descargas y comprobaciones

Elige el EXE de Windows o el ZIP para tu procesador Mac. Las sumas de los tres archivos están en SHA256SUMS.txt. Se verificó la actualización de Windows desde 9.2.0 y el arranque en Mac Intel. El paquete Apple Silicon se compiló para ARM64 en un Mac Intel y pasó las comprobaciones de firma e integridad. Queda pendiente el arranque de esta revisión en un Mac con chip Apple.

La [APK estable de Android](https://github.com/cristianbarallobre/selector-cine-365/releases/tag/v9.0.0) se sigue descargando desde la publicación v9.0.0.
